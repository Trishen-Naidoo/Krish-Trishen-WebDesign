# One Night on Campus

An inclusive event website built for the **Techwave Web Design Challenge**, designed for a event at VIT Mauritius where everyone has a place.

**Live demo:** https://krish-trishen-webdesign.netlify.app/

---

## About

The brief: design a website for a big event happening at our university. We created **One Night on Campus**, a fictional event built around one idea: *everyone should feel included*.

The site presents the event's different stands and zones, and includes a short quiz that helps students find the zone that suits them best.

> All event details on the site are fictional and were created for the challenge.

## Features

- **Find Your Zone quiz:** a quick interactive quiz that matches each student to the stand or zone that fits them best
- **Stands and zones:** an overview of the different areas of the event
- **Dark mode toggle:** switch between light and dark themes
- **Countdown timer:** counts down to the event
- **Responsive design:** works across screen sizes

## Built With

- HTML, CSS and JavaScript (single-file site)
- **MotionSites** for the UI design
- **Google AI Studio** for generating the code
- **Netlify** for deployment

The whole site was designed, assembled and deployed within a **30-minute** time limit. We directed the concept, features and quiz flow, then refined the AI-generated output to fit our idea.
